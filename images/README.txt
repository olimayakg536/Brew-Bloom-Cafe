BREW & BLOOM CAFÉ - ASSET & IMAGE DOCUMENTATION
========================================================================

This project uses carefully curated, high-resolution royalty-free images
from Unsplash CDN to keep the project lightweight, portable, and fast to load.

All images are loaded directly via HTTPS without requiring local binary storage.

OFFLINE USE / LOCAL IMAGES:
If you need to run this project fully offline without internet access:
1. Save your local photography or stock images (.jpg / .webp) inside this "images/" folder.
2. In index.html, update the image "src" attributes to point to "images/your-image-name.jpg".
3. In js/script.js, update the daily special "image" URLs to point to local assets.

Icons in this project:
- Clean inline SVGs and Unicode symbols are used to eliminate font/icon library dependencies.
